# Скин-трекер

Приложение следит за ценами на скины CS2 и простыми словами говорит: когда покупать, когда продавать, где дешевле.

## Как пользоваться
1. Нажми «+», начни вводить оружие (АК, 47, AWP…) — появятся подсказки.
2. Выбери скин, посмотри цены и совет, нажми «Добавить в список». Ошиблся — нажми «Отменить» внизу.
3. Всё. Приложение само проверяет цены в фоне и присылает уведомление, когда есть выгода.

## Площадки
Кнопка «Площадки» на главном экране: Skinport, Market.CSGO, DMarket, Steam. Включай и выключай, комиссию можно поправить.
Список скинов берётся целиком с Skinport и Market.CSGO (десятки тысяч названий).

## Сделки
Указал цену покупки → когда продал, нажми «Я продал этот скин» и впиши, сколько получил. В «Мои сделки» видно прибыль за неделю, месяц и всего.

## Уведомления
Ночью (23:00–8:00) тишина, если не выключить. Если выгодных скинов 3 и больше — одно общее уведомление.

## Настоящая история цен (GitHub)
1. Репозиторий должен быть открытым (public).
2. В нём должны быть файлы `.github/workflows/history.yml` и `tools/collect.py`.
3. Вкладка Actions → «Collect prices» → Run workflow. Дальше оно само запускается раз в 3 часа.
4. В приложении: Настройки → «История цен с GitHub» → впиши `логин/название-репозитория`.
Цены лежат в ветке `history`. Если запуск ругается на права: Settings репозитория → Actions → General → Workflow permissions → Read and write.

## Честно
- Совет считается по истории продаж Skinport; остальные площадки — для сравнения цен.
- Комиссии по умолчанию примерные (Skinport 12%, Market.CSGO 5%, DMarket 5%, Steam 13%).
- Деньги Steam нельзя вывести. CSFloat и Buff не подключены (нужны ключи).
- Рубли — по курсу ЦБ, примерные.
- Это не гарантия прибыли.

## Сборка
Залей проект в GitHub — вкладка Actions соберёт APK (файл `.github/workflows/build.yml`).
